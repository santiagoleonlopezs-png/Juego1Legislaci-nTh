# Las reglas del juego — actualización

- Ronda 1: sin límite de estrategias; se cierra individualmente al enviar.
- Facilitador: resultados por equipo y lista de decisiones elegidas, con productividad obtenida y estado de envío.
- Ronda 2: presupuesto de 60 créditos; sin límite de número de acciones, solo presupuesto.
- Después de enviar la política, aparece el mensaje para preparar su defensa y esperar la calificación.
- El facilitador sigue controlando la apertura de la siguiente ronda y la revelación del ranking.
- Ultimátum: mensaje más atractivo para el proponente.

## Instalación
Sube `index.html` y `firebase-config.js` en la misma carpeta de tu hosting. Si ya publicaste las reglas de Firestore del proyecto, no las reemplaces por el archivo de ejemplo sin comprobar su integración con las demás aplicaciones.

## Pruebas pendientes
La aplicación no se ha probado contra el proyecto Firebase real. Verifica con dos navegadores que el envío bloquea la edición, que los datos aparecen en el tablero y que los 60 créditos se respetan.
